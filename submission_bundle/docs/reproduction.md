## General Notes

- **Safety checks**: Scripts that create output directories will refuse to overwrite an existing non‑empty directory to protect prior results. Remove or rename the output directory if you wish to rerun the experiment.
- **Determinism**: Where randomness is involved (RANSAC sampling), a fixed seed (`42`) is used to ensure reproducible results across runs.
- **Environment**: The commands were developed and tested on Windows 11 with Python 3.12, OpenCV, NumPy, and Matplotlib (optional for visualization). No `requirements.txt` is provided; install dependencies via `pip` as needed.
- **Interpretation**: All reported quantities are in raw `uint16` depth values. The same‑FOV intrinsics scaling (used to create point clouds) is an unverified assumption; thus geometric interpretations in real‑world space (e.g., meter‑scale dimensions, plane orientations) are unknown. No measurement accuracy has been established against laser/tape ground truth.
- **Assignment compliance**: For a detailed mapping of assignment requirements to current implementation status, see `docs/compliance_matrix.md`.
